# 攻城推波 (`pg-siegepush`)

逆向塔防：你是攻方。三條推進路線由下往上通到敵方城堡，中間散著箭塔與弩台。
軍資每秒進帳，你組出自己的波次去砸城牆——守軍也會照節奏出城，往你的大營推。
三道防線一道比一道硬；城牆倒下算贏，大營被推平算輸。

類型：**逆向塔防** · 系列建議：街機

## 玩法

**部署**——按住底下的兵牌，拖到想去的那一路放手；或先點兵牌，再點戰場上的那一路。
每個兵吃軍資與人口，人口在單位陣亡後會放回來。

**推進路線**——每一路有一條可以拖的**集結線**：部隊只推進到那條線為止。
壓到城牆前就是全力突擊，往回拉就是屯兵、回防。三個路線鈕也可以一鍵在
「壓上」與「守營」之間切。真正的取捨在這裡：全部壓上牆會被箭塔洗掉，
全部守營又砸不動城牆。

**四種兵，明確相剋**

| 兵種 | 軍資／人口 | 特點 |
| --- | --- | --- |
| 民兵 | 4／1 | 便宜、跑得快，用來擋住第一線 |
| 弓手 | 7／1 | 射程蓋過近戰，身板薄，前面要有人擋 |
| 盾衛 | 10／2 | 替後排吃箭塔火力的肉盾 |
| 攻城槌 | 15／3 | 拆塔拆牆一槌抵十個人，對人幾乎沒殺傷力 |

拆掉箭塔除了拿賞金，之後每秒收入也會變高——先拆塔再推牆通常比硬上划算。

守軍的**營房有上限**：上一波沒清乾淨，下一波就放不滿。清場清得夠快，
城裡就擠不出兵。

鍵盤（桌機）：`1`–`4` 選兵、`A`／`S`／`D` 直接放進左中右、`Q`／`W`／`E` 切換該路壓上或守營。

戰績走宿主的 `/api/kv`；沒有宿主（直接開檔／離線）也照樣能玩，只是不留紀錄。

## 遊玩／安裝

純 HTML／CSS／JavaScript（無 build step）。本機直接開 `index.html`，
或經 Playgrounds／go 安裝。

## 開發

```bash
npx vitest run
```

`game.js` 是純邏輯（部署、行軍、戰鬥、經濟、波次、勝負），不碰 DOM；
`app.js` 只負責畫 state、把事件轉成音效與特效。規則與戰鬥都有測試覆蓋。
